# Лабораторна робота №5: Наслідування та поліморфізм

## Опис завдання (Варіант 1)
Необхідно визначити ієрархію цукерок та інших солодощів. Створити кілька об'єктів-цукерок та зібрати дитячий подарунок з визначенням його загальної ваги. Провести сортування цукерок у подарунку за вагою. Знайти цукерку в подарунку, що відповідає заданому діапазону вмісту шоколаду.

*   **`SweetException`** — кастомний клас винятку для обробки помилок при створенні об'єктів.
*   **`Sweet`** — абстрактний базовий клас, що описує загальні властивості будь-якої цукерки (назва, вага, ціна, вміст шоколаду).
*   **Класи-спадкоємці (`ChocolateCandy`, `Caramel`, `Jelly`)** — конкретні типи солодощів із додатковими унікальними властивостями.
*   **`Gift`** — клас, що агрегує солодощі за допомогою колекції `List<Sweet>` та надає методи для управління ними:
    *   Додавання цукерок.
    *   Підрахунок загальної ваги.
    *   Сортування за вагою.
    *   Пошук за діапазоном вмісту шоколаду.
*   **`laba5`** — клас з точкою входу `main`, що демонструє роботу всіх методів та обробку виключних ситуацій (`try-catch`).
